Implemented

  • Accessible names now include nested references, visible generated descendant text and native image labels, while excluding hidden descendants of visible references and hidden generated content. Semantic visibility follows slotted ancestry and excludes inert content. Boxless semantic containers remain eligible.
  • Native role fallback, contextual ARIA values, dormant error references, associated image maps, form labels and table-header relationships have regression coverage. Unprovable table, autocomplete and optional-reference claims request review.
  • Text and control contrast account for actual text fill, group opacity, partial-alpha backgrounds and first-line styling. Bounded multiply blending uses the browser compositing formula; an invisible unpainted word joiner does not create spurious uncertainty. Populated controls do not test unpainted placeholders. Unsupported paint effects request review. A shadow-root text-spacing probe is applied inside the affected root; budget exits disclose unchecked candidates.
  • Target geometry retains valid usable areas after overlaps, excludes disabled controls and checks equivalent controls before using the exception. Spatial indexing replaces the quadratic spacing scan. Bulk checks cooperate with cancellation.
  • CSS orientation declarations are checked against active conditions and computed styles. Overridden declarations are not failures. Other heuristics, including legacy motion, generic titles, time limits and bypass blocks, request review when the required facts cannot be established.
  • Element-scoped runs include the element itself and its open shadow root. Finding selectors use mutation-aware indexes. Task channels and audit caches are released.
  • Extension frame audits use private runtime transport and browser-verified frame ancestry. Slow frames get an audit deadline rather than the discovery deadline. Missing frames produce explicit review findings. Shadow-root frames are included.
  • The editor excludes orientation checks that now require browser rendering rather than silently returning a false pass. Site fixture claims count violations and review findings together.

Confirmed priorities

P1: Frame audits silently lose findings

src/extension/content.js:118,149,231 imposes a three-second reply timeout and drops missing replies without recording a coverage warning. In a real built-extension test, a visible frame with 16,000 unnamed buttons returned its findings after the top audit had returned ok: true with zero violations and no incomplete findings. A separate test placed a frame inside an open shadow root; no child frame was audited because enumeration uses document.querySelectorAll without collecting shadow roots.

Use extension-owned frame routing, explicit per-frame completion state and an appropriate audit deadline. A timeout must produce a partial result or error, not an apparently complete clean result. Source and executable evidence: frame probes, late reply probe, observations.

P1: Cross-origin audit snippets are exposed to page scripts

The frame protocol in src/extension/content.js:130,147-160 sends results with window.postMessage. Page scripts can observe these messages. A local proof used a parent on 127.0.0.1 and a child on localhost: the parent could not access contentDocument, but could read the dummy child input value LOCAL-DEMO-ONLY from the audit result. No external data was used. Reply matching also lacks event.source validation; adding that alone would not make window messages private from scripts in the destination page.

Move audit results through extension-owned runtime messaging with frame IDs and verified request ownership. Keep snippets out of page-visible messages. Local proof, result.

P1: Name and visibility helpers give wrong semantic verdicts

src/engine/lib/accessible-name.js:67,154,189 omits image alternatives inside labels, generated content on descendants and nested references, while admitting hidden descendants of a visible referenced label. A button visibly and programmatically named Save is reported as unnamed; a different truly unnamed button passes. These shared helper defects affect several rules.

src/engine/lib/dom.js:29,39,47 omits inert and assigned-slot ancestry from semantic visibility. Inert content is reported as an unnamed active control even when absent from the browser accessibility tree. Conversely, a nameless button styled display:contents is skipped despite remaining exposed as a button. src/engine/index.js:133 also omits a passed Element context itself, because querySelectorAll only visits descendants.

Correct the shared composed-tree and accessible-name model before adding individual rule exceptions. Keep visual rendering separate from accessibility-tree exposure. Evidence: independent full-engine semantics, core probes. Primary references: Accessible Name Computation, HTML inert subtrees.

P1: Contrast can use colours that are not painted

1.4.3-control-contrast.js:62,88,97 reports white text on a black gradient as 1:1 rather than 21:1, composites group opacity incorrectly, and ignores text-fill colour. The main text rule mishandles an own-element filter and includes an unpainted base colour when first-line styling covers all the text.

The reverse error also exists: lib/contrast.js:1270,1284 treats a black image at 49% alpha as wholly transparent. Grey text on the resulting grey background passes, although the rendered colour pair is approximately 1.94:1. Shared paint resolution, conservative uncertainty handling and adversarial pixel fixtures are required. Evidence: full-engine visual checks, readable field, missed low contrast. Source: Contrast Minimum.

P1: Target geometry and exceptions overstate failures

2.5.8-target-size.js:431-454,567 selects the largest remaining rectangle by area. A 100 by 50 target overlapped at its upper right retains a fully usable 24 by 50 left strip. The engine instead chooses a 100 by 23 bottom strip and asserts a failure. Additional fixtures wrongly flag disabled buttons and small buttons with working equivalent large controls.

The implementation must test whether a qualifying square exists and honour scope and exceptions. If equivalence or essentiality cannot be established, ask for review rather than asserting their absence. Independent evidence, W3C size requirement and exceptions.

P1: Syntax and heuristics are being promoted into WCAG violations

Confirmed examples include a valid fallback ARIA token rejected by an enum, a role typo on a native button whose role remains intact, dormant error references, ineffective orientation declarations, a static blink element, a stopped marquee and a paste handler whose preventDefault call is in an unreachable branch. The paste event was dispatched and remained uncancelled. Four unique controls on a single page are also mistaken for repeated navigation blocks that require bypassing.

These branches need evidence of the criterion's actual failure. Authoring errors can be useful review findings, but they are not automatically WCAG failures. The per-rule notes distinguish confirmed examples from broader suspected scope problems. Semantic evidence, interaction evidence, ARIA error handling, ARIA current.

P2: Untested content is sometimes recorded as passing

1.4.12-text-spacing.js:47 returns passes above its 20,000-element limit. Its document-level stylesheet also fails to apply to shadow text with explicit spacing styles; the engine passes a fixture that clips after the intended overrides are correctly applied in its shadow root. Timed-out image samples remain cached, preventing a later audit from retrying the same resource. The CLI's ordinary run audits only the top document, whereas the extension and bookmarklet aggregate some frames.

Represent skipped rules, inaccessible roots, timeouts and untested states explicitly. A rule pass must describe a completed applicable test, not a budget exit. The manual checklist is valuable but does not substitute for recording an attempted rule that never ran. Spacing evidence, Text Spacing.

Recommended repair order

  • Remove silent partial-success results and secure frame-result transport.
  • Correct shared accessible-name, effective-role and semantic visibility handling.
  • Unify contrast paint handling and stop treating nonzero alpha as invisible.
  • Fix target-size geometry and exception handling, then optimise and yield within its set evaluation.
  • Demote unsupported syntax/heuristic assertions to review until stronger evidence exists.
  • Expose budget skips and repair shadow-root probe application.
  • Fix runtime support declarations, cache lifecycle and selector serialization.
  • Run all engine gates plus a same-DOM before/after corpus differential, adjudicating every newly asserted failure and significant disappearance, before publishing an engine update.

Do not claim 100% accuracy from finite fixtures. The enforceable objective is narrower and useful: every asserted finding has demonstrable evidence, uncertainty remains visible, and unsupported checks cannot silently manufacture a clean audit. Human judgment is still needed for complete pages and processes under WCAG conformance requirements.

1. Name computation reports named controls as nameless, and misses unnamed controls

Other source-verified limits and policy distinctions

  • Main bold cutoff is 600 at src/engine/lib/contrast.js:1697. Its comment records an explicit user policy. Do not label this an accidental defect or silently change it to 700. WCAG uses the word bold; equivalence across fonts remains an interpretation.
  • Text spacing returns passes above 20,000 candidate elements (:47). This is a performance abstention expressed as success. Better expose not-tested/incomplete at rule level. Existing baseline clipping also clears later increased loss (:84). Containers with overflow:visible can overlap and lose legibility, but are excluded at :53. These are source-confirmed misses; no large stress run was performed here.
  • Reflow's at 320px ... will be worse (:23) is an unjustified guarantee. A media query can replace a wide desktop layout with a single-column mobile layout. Current overflow is measured; future overflow is not. The rule should state a review prompt without the prediction. Horizontal writing needs the 256px height branch. No specific reflow reproduction run here.
  • Control text does not use its own full text renderer's shadow/outline/filter safeguards. The three measured cases demonstrate the common architectural gap; avoid adding independent approximations that diverge again.
  • The current G183 July 2026 revision was checked directly. A 3:1 link distinction alone is sufficient in the current text. An older assumption requiring an extra hover/focus cue would be an incorrect audit finding.

Performance findings: suspected costs, not measured bottlenecks

No full-site timing or large synthetic performance run was performed here while parent verification was active.

  • imageRangeCache at lib/contrast.js:1209 and transparentImages at :221 persist across audits; the former keys by URL, overlays and grid and has no bound. Dynamic image URLs and many overlay/grid combinations grow retained entries. Main imageVsText first samples at 32x32 (:154), followed by a possibly larger grid (:714), duplicating image decode/draw work under different keys. Measure before choosing a cache policy.
  • The 1,500ms image timeout at lib/contrast.js:1245 resolves null without cancelling image load. A timed-out load can later draw and walk up to a 1024x1024 grid. A failed result also remains cached, preventing later retry even after the image becomes available. Source-confirmed lifecycle behavior, not elapsed-time measurement.
  • Pseudo, media, panel and opacity caches are valuable. Nevertheless pseudoBackdropForText scans the ancestor chain per text, backdropHazard scans collected media/panels per candidate, and out-of-flow fallback can style-scan up to 2,000 descendants per text at color-contrast.js:1039. Long deeply nested or many-card pages are natural stress dimensions. Preserve cache correctness across root/document boundaries.
  • Text spacing intentionally forces layout twice. Its threshold bounds costs but currently hides the abstention. Prefer transparent budgeting over pass fabrication.
